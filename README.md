# 音MADer 地图 (Alpha)

## 运行

需要 Node.js 18 或更高版本。项目不依赖第三方 Node 包：

```sh
npm start
```

浏览器打开 `http://localhost:3000`。服务端首次启动时会创建 `data/members.json`。部署前应为该文件配置持久化存储，并通过 HTTPS 提供页面，浏览器定位功能在非 localhost 环境需要安全上下文。

## 实现结构

- `server.js`：Node.js HTTP 服务，提供静态文件和 `/api/members`、`/api/register` 两个接口。
- `public/`：原生 HTML、CSS、JavaScript 前端。
- `public/locations.js`：省级地区、地级市 / 地区选择项和国家 / 地区选择项。
- `map_china_2019.jpg`：原始地图海报；`public/china-map.jpg` 是裁掉图例后的地图显示底图。
- `data/members.json`：服务端成员记录；map_sid 不会通过成员查询接口公开。

成员提交时以昵称（忽略大小写）查重。首次加入生成随机 map_sid；更新时要求 SID 匹配。浏览器将 SID 保存在 localStorage，以“？”按钮展示。表单中的定位按钮先申请浏览器设备定位并将坐标转成省市；定位失败后再查询 IP 归属地，用户也可以直接手动填写。点击定位按钮即代表用户选择了这项功能，坐标会发送给反向地理编码服务，GPS 失败时 IP 查询会将访问请求发送到 IP 归属地服务。

家乡和活跃地区都用省份、城市 / 地区两个级联下拉框；选“海外”后第二项切换为国家 / 地区。内置 34 个省级选项（含港澳台）和 378 个地级及省直辖市级地区选项；国家 / 地区名称按 ISO 区域代码本地化生成。地图将所有海外成员聚合到左下方的留白标记。地图缩放经动画过渡，拖动和双指缩放保持直接响应。

主页根据各省成员数据绘制数量气泡。气泡数为家乡或最近活跃省份与该省匹配的去重成员数；点击后分别展示家乡名单和最近活跃名单。实时搜索可匹配昵称、B站 UID、省份和城市，并显示成员卡片。气泡中心按裁切图逐省手动校准，因此属于图片坐标近似值；底图仍是静态 JPG，不是可查询的行政区矢量地图。鼠标滚轮、双指和拖动均作用于地图视窗；页面禁用浏览器手势缩放。

## 已知部署限制

成员数据用 JSON 文件保存，适合单机 Alpha 演示；多实例部署、并发写入、账户找回和滥用防护应迁移到数据库并添加速率限制。生产部署需通过 `HTTPS`、持久化卷和反向代理提供服务，并更换文件存储为数据库。成员索引是公开展示内容，注册时应只填写愿意公开的信息。
